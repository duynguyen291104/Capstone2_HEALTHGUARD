# Model card

## Intended use

FallGuard's MVP is a causal research model for detecting a possible fall from a
single RGB camera and verifying whether the person remains lying or appears to
recover. It supports capstone experimentation, controlled demonstrations, and
integration testing.

It is not a certified medical device. It must not be the sole mechanism used to
protect a person or dispatch emergency care.

## Inputs and outputs

The temporal model consumes 40 normalized MediaPipe pose frames sampled at
20 FPS. A shared causal GRU/LSTM/TCN encoder has two heads:

- posture: `UPRIGHT`, `TRANSITION`, `LYING`;
- fall event: probability that the current causal window belongs to a fall.

The state machine combines model probability, duration, pose motion, and
post-fall posture into `NORMAL`, `POSSIBLE_FALL`, `VERIFYING`,
`CONFIRMED_FALL`, or `RECOVERED`.

## Evaluation contract

Metrics are generated by code and stored with the checkpoint. No performance
number is claimed in documentation before the corresponding experiment has run.
Reports include posture and event precision/recall/F1, false alarms per video,
and detection delay where frame-level event timing is available.

Splits group all windows from one sequence together. For URFD this is
cross-sequence rather than cross-subject evaluation.

## Known failure modes

- deliberate lying down, fast sitting, kneeling, exercise, or wheelchair use;
- partial occlusion, people leaving the frame, very low light, and unusual views;
- more than one person when no external tracker is configured;
- camera motion or a floor plane very different from training data;
- acted public falls that do not represent frail or real emergency falls.

Every alert should provide evidence and remain reviewable by a caregiver.
